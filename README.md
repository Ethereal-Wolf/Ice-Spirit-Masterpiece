Transform your Titan Quest experience into the ultimate mythological adventure.

Ice Spirit' Masterpiece is a carefully crafted gameplay overhaul for Titan Quest Anniversary Edition, combining some of the community's best mods into one polished, fully integrated experience.

Instead of installing and troubleshooting multiple mods yourself, simply subscribe and play.

Battle larger hordes, face deadlier enemies, collect better loot, command legendary companions, and push your hero beyond the limits of the original game—all while staying true to the spirit of Titan Quest.

Performance Notice

This overhaul pushes Titan Quest's entity scaling close to the engine's stable limit.

To help prevent out-of-memory crashes, avoid speedrunning through multiple areas or dragging several monster camps behind you at once.

Clear enemy packs progressively for the most stable experience.

Installation

Two ways to play.

Option 1 — Custom Quest (Recommended)

1. Subscribe on Steam Workshop.
2. Launch Titan Quest Anniversary Edition.
3. Select Play Custom Quest.
4. Choose Ice Spirit' Masterpiece.
5. Create or load a character.

No manual installation required.

Option 2 — Main Campaign (Steam Achievements Enabled)

Replace the game's database with the one included in this Workshop item.

Back Up Your Original Database

Navigate to:

...\Steam\steamapps\common\Titan Quest Anniversary Edition\Database\

Back up:

Database.arz

before making any changes.

Locate the Mod Database

Browse to:

...\SteamLibrary\steamapps\workshop\content\475150\3755062270\icespiritmasterpiece\database\

Locate:

IceSpiritMasterpiece.arz

Install

• Rename IceSpiritMasterpiece.arz to Database.arz

• Copy it into:

...\Steam\steamapps\common\Titan Quest Anniversary Edition\Database\

• Replace the existing file when prompted.

Launch Titan Quest normally to enjoy the overhaul while continuing to earn Steam achievements.

Restore Vanilla

Replace the modified Database.arz with your backup.

Note: Steam updates or verifying game files may restore the original database. Simply repeat the installation if necessary.
